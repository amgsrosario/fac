## Correcções implementadas pelo executor

- MINOR-001: a CLI não se limita a Console != null. Em Java 22+ exige resposta positiva de Console.isTerminal() via reflexão compatível com release 21; API ausente/inacessível ou erro recusa. Em Java 21 preserva a semântica terminal de System.console(). Recusa antes de ler autorização/input/secreto com saída própria **3** e mensagem de terminal. Teste subprocesso passa stdin não vazio redireccionado com confirmação completa, exigindo exactamente essa saída/mensagem, sem depender de EOF ou password/base inválida. Testes da política simulam runtimes 22/25; runtime nativo disponível é 21.0.12.1. Fonte primária: [Java SE 22 Console.isTerminal, since 22](https://docs.oracle.com/en/java/javase/22/docs/api/java.base/java/io/Console.html#isTerminal()). Não se declara execução nativa em Java 22+ inexistente no ambiente.
- MINOR-002: a guarda SQL recusa também owner do schema, CREATE no schema, ownership das tabelas Utilizador/comprovativo/auditoria e sequência de auditoria, e das três funções locais. Também recusa DML directo concedido nas três tabelas, impondo a fronteira declarada. Mantém atributos privilegiados/memberships/dono da base. Recusa antes de qualquer leitura privilegiada de identidade, para que o owner da própria função não passe por erro incidental de pg_control_system(). Testes com roles não-superuser, sem ownership da base; ownership de tabela testado mesmo após retirar DML, schema owner mesmo sem CREATE, funções, membership e CREATE separados, role restrita positiva.
- O-1: Java e SQL exigem explicitamente READ COMMITTED. A guarda SQL é anterior aos locks/leitura da identidade, inclusive chamadas SQL directas com transacção própria. READ UNCOMMITTED também é recusado, embora PostgreSQL lhe atribua comportamento próximo; contrato exige o nível explícito. Testes Java e SQL para RU/RR/SERIALIZABLE, sem escritas; concorrência e rollback READ COMMITTED revalidados de forma dirigida.
